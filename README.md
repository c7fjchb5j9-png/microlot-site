# Микролот — сайт-концепт кофейни

Одностраничный сайт спешелти-кофейни «Микролот» (Санкт-Петербург, Ленинский пр., 166 и Варшавская, 23 к1).
Сайт статичный, без бэкенда: Vite + чистые HTML/CSS/JS, анимации на GSAP + ScrollTrigger, плавный скролл на Lenis.
Шрифты (Cormorant Garamond, Onest, JetBrains Mono) лежат локально, внешних CDN нет.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev       # http://localhost:5173 — правки в JSON подхватываются на лету
npm run build     # готовый сайт в папке dist/
npm run preview   # посмотреть собранную версию
```

Перед `dev` и `build` автоматически запускается `npm run images`: фото из `images/` конвертируются
в WebP нескольких размеров (`public/img/`).

## Где менять содержимое

Все тексты, цены, адреса и часы лежат в двух файлах. Код трогать не нужно.

### Меню и цены — `src/data/menu.json`

```json
{ "name": "Капучино", "size": "250 мл", "price": 230 }
```

* `categories` — вкладки меню. Порядок в файле совпадает с порядком на сайте.
* `more` — список «Ещё у нас» (без цен).
* `syrupsNote` — подпись про сиропы.

### Часы работы — `src/data/site.json` → `points[].schedule`

```json
"schedule": {
  "mon": ["07:30", "21:00"],
  "sat": ["09:00", "21:00"]
}
```

Дни: `mon tue wed thu fri sat sun`. Выходной — просто удалите строку дня.
Из этого расписания считается всё сразу: индикатор «Открыто до 21:00 / Закрыто, откроемся в 07:30»
(по московскому времени), часы в первом экране, в карточках точек, в подвале и в JSON-LD для поисковиков.

### Остальное в `site.json`

| Ключ | Что это |
|---|---|
| `contacts` | телефон, Telegram, VK, WhatsApp |
| `ratings` | рейтинги Яндекс Карт и 2ГИС (меняются, обновляйте раз в месяц) |
| `steps` | 4 шага «Что такое микролот» |
| `beans.cards` | карточки пачек зерна. Пустое поле отображается как пустая строка для заполнения |
| `why` | пункты «За что нас любят гости» |
| `gallery` | фото для «Атмосферы»: `src` — имя файла из `images/` без расширения |
| `siteUrl` | адрес сайта (нужен для Open Graph и JSON-LD) |

### Фото

Положите `.jpg`/`.png` в `images/` и добавьте запись в `gallery` в `site.json`.
Логотип — `images/logo.jpg`.

### Картинка для соцсетей

`public/og.png` (1200×630) генерируется командой `npm run og`. Для неё нужен Playwright:
`npx playwright install chromium`.

## Демо-режим

В `src/data/site.json` стоит флаг:

```json
"demo": true
```

Пока он включён:

* в углу видна плашка «Концепт сайта · Михаил»;
* в `<head>` стоит `<meta name="robots" content="noindex, nofollow">`;
* `robots.txt` запрещает индексацию.

Чтобы запустить сайт по-настоящему, поставьте `"demo": false` и пересоберите (`npm run build`
или просто push в `main`). Плашка и запрет индексации исчезнут, `robots.txt` разрешит индексацию.
Заодно обновите `siteUrl`.

## Деплой на GitHub Pages

Деплой настроен в `.github/workflows/deploy.yml`: каждый push в ветку `main` собирает сайт и публикует его.

1. Создайте репозиторий на GitHub и запушьте код в `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Сайт появится по адресу `https://<пользователь>.github.io/<репозиторий>/`.

Путь `base` для Vite подставляется автоматически из имени репозитория (переменная `BASE_PATH`).
Для своего домена (например, `microlot.coffee`) задайте в workflow `BASE_PATH: /`
и добавьте файл `public/CNAME` с доменом.

## Анимации и доступность

* GSAP подгружается отдельным файлом уже после первой отрисовки и не тормозит загрузку.
* Если в системе включено «Уменьшить движение» (`prefers-reduced-motion`), анимации и плавный скролл
  отключаются, весь контент виден сразу.
* Без JavaScript сайт тоже работает: меню показывает первую вкладку, ссылки и карта-схема доступны.
* Живая Яндекс-карта грузится, только когда вы до неё доскроллили. Если она не загрузилась, остаётся SVG-схема.
